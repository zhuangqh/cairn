## Shared constraints for the other families

First Stone, Monthly Ascent and Time Marks prompts combine this base prompt with the per-asset subject from the tables below.

```text
Use case: stylized-concept. Generate exactly ONE standalone transparent production icon matching the specified artifact in the approved Cairn reference board. Reference board is a style reference, not an edit target. Softly chamfered nearly square mineral seal, straight frontal view, shallow sculptural relief, upper-left soft studio light, quiet premium mineral craftsmanship. Entire centered seal occupies 84% of square canvas width AND height, equal genuinely transparent margins, pristine anti-aliased alpha edges. Preserve broad legible shapes at small UI sizes. No text, labels, numerals, board, other stages, floor, outside shadow, aura, sparkles, arrows, clock markings, mountain peaks unless present in the requested family, floating fragments or stray colored pixels.
```
